## Overview

ItemBrowser is a PEAK game mod that adds an enhanced item browsing interface allowing players to search their inventory, filter items by type and rarity, compare item stats side-by-side, and organize gear sets for different activity loadouts. It integrates with PEAK's existing UI to provide a cleaner and more efficient item management experience.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **ItemBrowser** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Item Search** | Search your full inventory by name, type, or stat in real time |
| **Rarity Filter** | Filter items by rarity tier to quickly locate specific quality items |
| **Stat Comparison** | Compare two items side-by-side to make informed upgrade decisions |
| **Gear Sets** | Save and switch named gear set configurations for different content |
